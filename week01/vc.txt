5. Thoroughly explain these concepts (this likely cannot be done in less than 100 words)
Version control is a system for tracking the progress and history of a project over time. Version control allows
team members or even individuals to see what changes were made, who made the changes, and what the benefit of the change is. 
example of a version control system is Git. Git allows every distributor to have a full copy of the entire project and its complete 
history stored locally on their own machine, rather than depending on constant access to one central server. We also have GitHub, 
which is completely different from git. GitHub is a web-based service that hosts git repositories remotely, acting as a central hub 
where teams can push their changes so that every member can stay synchronized.
